# Digi Tiranga 🇮🇳

> Wave the National Flag of India with Pride.

An authentic web recreation of [digitiranga.com](https://digitiranga.com), engineered as a Progressive Web App (PWA) ready for deployment on GitHub Pages.

## ✨ Experience

- **Physics-driven Tiranga** — Verlet cloth simulation running at 60 FPS with WebGL shading, Ashoka Chakra rendering, and procedural Canvas fallback.
- **Natural Swipe Mechanics** — Single swipes or hold-and-sweep gestures to wave the Tiranga with spring-pole inertia.
- **Josh Meter & Celebrations** — Builds up Josh energy as you wave; triggers celebratory crowd roars, dhol beats, and tricolor petal bursts.
- **Tiers & Progression** — Earn honorary ranks from *Just Joined* to *Tiranga Titan* as your wave count rises.
- **Our Goal Screen** — Dynamic SVG map of India filling up in tricolor as wave milestones are achieved.
- **Audio Feedback** — Authentic dhol rhythm, crowd roar, and chime sound effects powered by the Web Audio API (with mute toggle).
- **Social Sharing** — Generate high-resolution celebration cards and share instantly to WhatsApp.
- **PWA & Offline Capable** — Installable directly as a native-feeling mobile app via browser links with full offline support.

## 🚀 Deployment to GitHub Pages

1. In your GitHub repository, navigate to **Settings → Pages**.
2. Under **Build and deployment**, select **Source** as `Deploy from a branch`.
3. Choose the `main` branch and `/ (root)` folder, then click **Save**.
4. Your PWA will be live at `https://<username>.github.io/<repo-name>/`.

## 📱 Mobile App (PWA) Usage

- **Android (Chrome)**: Tap the menu (⋮) → **Install app** or **Add to Home screen**.
- **iOS (Safari)**: Tap the Share button (⎋) → **Add to Home Screen**.
- Once installed, it launches full-screen without address bar clutter, working offline seamlessly.
