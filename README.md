# Tricolor Digital Experience

An original tricolor-themed browser game portal for GitHub Pages.

## Features
- Colour pick and number pick rounds with simulated demo points.
- Local demo balance, round history, results and best streak.
- Responsive navigation, instructions dialog and touch/keyboard-friendly controls.
- No real-money wagering, deposits, withdrawals, accounts, or payment integrations.

## Run and deploy
Open `index.html` locally. To publish, use **Settings → Pages → Deploy from a branch → main → / (root)**.

All points are fictional, have no cash value and are only for local gameplay. The interface and implementation are original; this project does not use third-party branding or assets.
